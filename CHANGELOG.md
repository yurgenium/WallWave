## 0.4.0

Настройки разделены на интересы, автоматизацию, изображения, AI, клавиши, мониторы и резервные копии. В библиотеке видны статусы загрузки, анализа и смены, число неоценённых и понравившихся обоев, занятое место.

Нажмите **«Кадр»** на скачанных обоях, выберите монитор и режим: **«Заполнить экран»** обрезает края, **«Вписать целиком»** сохраняет всё изображение с полями. Ползунки перемещают кадр, переключатель отражает его по горизонтали. Предпросмотр использует пропорции выбранного экрана. «Сохранить кадр» меняет настройки для следующей установки; «Сохранить и установить» сразу применяет их.

Кадр можно открыть и из раздела **«Мониторы»**. Шаблон монитора действует на обои без индивидуальных настроек; собственный кадр имеет приоритет. Кнопка «Убрать свой кадр» возвращает шаблон. Для каждого подключённого монитора приложение создаёт изображение его разрешения. Успешная смена заменяет только предыдущую подготовленную копию; исходник остаётся.

Новые загрузки сохраняют полный исходник. Он учитывается в лимите диска и включается в экспорт вместе с настройками кадра. Старые экспорты версии 0.3 также восстанавливаются. Если у старых обоев исходник ещё не сохранён, редактор использует кеш и предлагает **«Обновить исходник»** из включённого источника. Если источник больше недоступен, сохранённая копия остаётся доступна, но ранее обрезанные края восстановить из неё нельзя.

## 0.3.0

- В настройках выберите число показов до замены (2–10, по умолчанию 3), запас неоценённых обоев и разнообразие 0–100. Для пополнения включите автоматический поиск. Автоматические загрузки поддерживают заданный запас; ручная загрузка может добавить больше. Часть поиска при повышении разнообразия обращается к общим популярным обоям, сохраняя ограничения контента и исключённые теги.
- Показ считается после 30 секунд активности с разблокированным экраном вне полноэкранной работы. Счётчики служебные, история показов не добавлена. При игре, блокировке и батарее автоматические задачи откладываются. Случайная смена использует сохранённые счётчики, чтобы пройти доступные изображения до повторов.
- Выбирай монитор в библиотеке перед установкой обоев. В настройках есть отдельные категории, интересы и таймер для каждого монитора. Расписание принимает время через запятую: `09:00, 18:00` по часам Windows. Запуск с Windows включается через трей; смена при запуске и после пробуждения настраивается отдельно.
- Кнопка «Для работы» ставит спокойный нейтральный фон и скрывает взрослые изображения. Режим сохраняется до явного действия «Выйти из режима работы». Глобальные сочетания задаются в настройках, например `Ctrl+Alt+N`; пустое поле отключает действие. Если сочетание занято, под полем появится сообщение. Новые действия доступны в трее.
- Для экспорта укажите существующую папку: внутри появится новая папка `WallWave-export-…`. Для восстановления укажите эту папку целиком. Экспорт содержит скачанные обои, настройки и оценки; API-ключи не включаются. Перед заменой прежняя библиотека сохраняется в `library.before-restore-…`. После восстановления нажмите «Продолжить» в библиотеке или трее. Для полного отката закройте программу через «Выход», переименуйте новую `library` и верните прежней папке имя `library`.
- Настройки кадра добавлены в версии 0.4.0. Второй монитор и события сна проверены на уровне логики; для проверки реального оборудования нужен второй подключённый экран.
