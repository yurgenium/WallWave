# История изменений

## 0.6.11 — 2026-10-26

- При конфликте общего фильтра категорий с настройками мониторов приложение показывает причину и предлагает явно включить наследование общего фильтра для затронутых экранов.
- Новые настройки монитора по умолчанию наследуют общий фильтр; существующие индивидуальные ограничения сохраняются, пока пользователь сам их не изменит.
- Вместо общего «Недоступно» показываются отдельные сообщения о конфликте фильтров, запрещённой категории и исключённых тегах. Диагностика различает сохранённый и действующий фильтры монитора.

## 0.6.10 — 2026-10-26

- Исправлено сохранение диагностического JSON в настольной версии с IPC: кнопка открывает штатное окно выбора файла. Браузерная версия сохраняет прежнее скачивание по HTTP.
- После неудачной установки обоев следующая попытка выполняется заново: прежняя ошибка в очереди операций больше не блокирует смену фона после исправления настроек.
- Диагностический отчёт содержит реальную версию сборки, ОС, точное действие, этап и причину отказа, настройки категорий и число доступных кандидатов для каждого монитора.
- Последние операции и последняя ошибка сохраняются между запусками. Успешные действия не затирают сведения о предыдущем сбое; прерванная операция отмечается при следующем запуске.
- Отказ `notAvailable` при подборе и установке различает ограничения рейтинга, исключённые теги, недоступный источник и отсутствующее изображение. Для ошибок Windows сохраняются операция, код завершения и HRESULT.
- Ключи, адреса источников, названия и теги изображений, пути, имена профилей и идентификаторы мониторов не включаются в отчёт и его локальную историю.

## 0.6.9 — 2026-10-23

- Настольное приложение передаёт интерфейс, настройки и скачанные изображения через межпроцессный канал без локального HTTP-сервера. Сетевые лимиты для скачивания больше не замедляют работу локальной библиотеки.
- Плавающая панель и значок её возврата скрываются в настройках и появляются при выходе из них.
- Миниатюры скачанных обоев кэшируются на час; изменение карточки больше не перемещает остальные карточки в библиотеке. Декодирование миниатюр выполняется асинхронно.
- Ошибки фоновых операций сохраняются в журнале запуска с временем и кодом, без названий обоев, адресов источников и ключей.

## 0.6.8 — 2026-10-22

- Исправлена проверка Rule34: пустой ответ API при отсутствии результатов больше не считается неправильным JSON-каталогом. Пустая выдача корректно отображается без изменения выбранных категорий.
- Ошибки авторизации, ограничения запросов и неожиданные ответы booru API показываются отдельными понятными сообщениями.

## 0.6.7 — 2026-10-21

- Краткий скачок нагрузки CPU или GPU больше не прерывает подбор с ИИ. Ограничение по нагрузке срабатывает после 10 секунд устойчивого превышения, снятие ограничения требует 5 секунд нормальных показателей. Защита при нехватке памяти и немедленная пауза при блокировке экрана, полноэкранном приложении и других заданных ограничениях сохранены.

## 0.6.6 — 2026-10-21

- Исправлен сброс полного просмотра и выбранной папки при быстром возврате отложенных или нейтральных обоев в непросмотренные. Ускорен поиск следующего изображения в больших списках.
- Панель папок закрепляется сверху при прокрутке и становится полупрозрачной до наведения. Нажатие на текущую обычную или пользовательскую папку возвращает список к началу без отдельной кнопки.

## 0.6.5 — 2026-10-21

- Убран счётчик полученного за сеанс объёма из панели. Текущая скорость загрузки показывается отдельной строкой в КБ/с только при активном скачивании; при простое строка исчезает.

## 0.6.4 — 2026-10-21

- Исправлено мгновенное исчезновение панели при включённом уменьшении анимации в системе. Панель равномерно теряет непрозрачность за 1,2 секунды и скрывается только после завершения перехода; возврат остаётся быстрым.

## 0.6.3 — 2026-10-21

- Скрытие свёрнутой панели стало плавнее и медленнее. Наведение в её область отменяет исчезновение и удерживает панель до ухода с карточки; развёрнутая панель не скрывается. У скрытой панели остаётся маленький значок возврата у правого края, не перекрывающий реакции.

## 0.6.2 — 2026-10-21

- Плавающая панель больше не перемещается от курсора. При наведении на перекрытую карточку она плавно скрывается и возвращается после ухода указателя. Карточки под панелью доступны для нажатия; элементы самой панели и управление с клавиатуры остаются доступны.

## 0.6.1 — 2026-10-21

- Переработана плавающая панель: компактный статус, две шкалы подбора, быстрые предыдущие/следующие обои, закрепление, независимая пауза смены, общий интервал и выбор пользовательской папки. При наведении на перекрытую карточку панель уходит влево.
- Помощь и диагностика перенесены в отдельный пункт настроек. В панели обращение к помощи появляется при потере связи или серьёзной ошибке сохранения; дублирующие счётчики убраны.
- Добавлен мастер подключения сайтов с распознаванием известных площадок, совместимых Danbooru JSON, Gelbooru / DAPI JSON и каталогов приложения. Набор полей определяется способом доступа; предусмотрен ручной выбор совместимого формата.
- Проверка поиска и миниатюры не добавляет изображения в библиотеку и не скачивает оригиналы. Источник сохраняется отдельным действием. Для неподдерживаемых сайтов открывается форма запроса в GitHub Issues без ключей и параметров адреса.
- Технические работы DeviantArt распознаются отдельно от неверных данных доступа; повторные запросы ограничиваются. Новые сайты не включаются обновлением.
- Интерфейс и инструкции обновлены на русском и английском.

## 0.6.0 — 2026-10-21

- Профили с отдельными библиотеками, оценками, тегами, настройками, источниками и ключами. При создании можно скопировать настройки основного профиля; библиотека и ключи не копируются. Данные удалённого профиля сохраняются для восстановления.
- Пользовательские папки без копирования файлов и изменения оценок; добавление из карточки или просмотра сохраняет фокус. Для показа одной папки используется её собственный цикл, сначала выбирающий давно не показанные изображения.
- Закрепление текущих обоев на 1, 6, 12 часов, до ручной смены или выбранного времени. Ввод времени — 24-часовой, двоеточие добавляется автоматически, ошибочное значение откатывается с предупреждением. После окончания срока выполняется одна смена, затем действует обычное расписание.
- В трее добавлены закрепление и возврат предыдущих обоев. Горячая клавиша смены подтверждается уведомлением. Повторные расчёты рейтинга при сортировке устранены.
- При занятости ПК останавливается и ручной подбор с ИИ, включая активный процесс модели и передачи файлов. Общий кеш модели используется всеми профилями, предпочтения остаются раздельными.
- После отмены загрузки автоматический подбор и автоанализ приостанавливаются на 60 минут по умолчанию; интервал меняется в настройках. Ручной подбор и повтор незавершённых загрузок снимают эту паузу.
- Исправлены статусы отмены, анализа и расписания. Полный пересмотр состава плавающей панели и добавление произвольных сайтов оставлены для отдельного обсуждения.
- Добавлен локальный отчёт диагностики без ключей, личных тегов, названий изображений и адресов источников; доступны журнал и ссылка для сообщения об ошибке. Загрузка модели, оригиналов, миниатюр и запросы к площадкам отображаются раздельно.


## 0.5.23 — 2026-10-20

- Исправлено подключение окна при медленном ответе большой библиотеки: периодические запросы состояния выполняются по одному, долгий ответ больше не отбрасывается из-за следующего запроса.
- После изменения оценки или настроек выполняется свежий запрос, чтобы более ранний ответ не вернул устаревшее состояние интерфейса.
- Большие ответы состояния передаются с gzip-сжатием, если окно его поддерживает. Настройки кеширования и ограничения доступа сохранены.
- Ожидание ответа увеличено до 30 секунд; после временной потери связи окно восстанавливается автоматически и убирает сообщение об ошибке. Текст обновлён на русском и английском.


## 0.5.22 — 2026-10-17

- У подбора две подписанные шкалы: подготовленные к загрузке обои и фактически скачанные файлы. Цель соответствует размеру партии с учётом свободного места в запасе; кандидаты и байты отдельного файла её не меняют. Частичный результат и отмена сохраняют реальный счётчик скачанных файлов.
- Добавлена очередь до четырёх прошедших отбор изображений с двумя параллельными передачами оригиналов. Запись файлов и проверка свободного места выполняются последовательно; текущие настройки и фильтр ИИ повторно проверяются перед сохранением.
- Отбор по миниатюре предшествует запросу метаданных. Подробности Wallhaven кешируются на сутки; известные слишком большие файлы пропускаются заранее. При равной оценке предпочтение получают меньшие оригиналы. Ранее оценённые и намеренно очищенные файлы не восстанавливаются подбором автоматически.
- Медленная передача ограничена 90 секундами без автоматических повторов того же файла; он откладывается на 10 минут и заменяется другим кандидатом. Повторяющиеся сетевые ошибки временно исключают источник из текущего подбора; остальные площадки продолжают работу. Прежний короткий предел проверки увеличен; две минуты без новых подходящих вариантов останавливают бесполезный поиск. Общий предел начала новых поисков и передач — восемь минут; уже начатые передачи завершаются в пределах своего тайм-аута.
- «Продолжить подбор» использует тот же размер партии и понятные счётчики. Запросы API сохраняют интервалы и ожидание ограничений площадок.
- Исправлен запрос токена DeviantArt: неподдерживаемый параметр scope удалён. Лимит скачиваний площадки отображается отдельно от ошибки авторизации; пауза повторных запросов сохраняется после перезапуска.
- Полностью сохранённая модель CLIP загружается из локального кеша без повторного обращения к сети.

## 0.5.21 — 2026-10-17

- Карточки источников сохраняют размеры и располагаются плотными колонками: следующие карточки поднимаются сразу под предыдущие, независимо от высоты соседних. Раскладка адаптируется к размеру окна, языку и содержимому без дополнительного JavaScript.

## 0.5.20 — 2026-10-17

- Исправлена вставка данных доступа после возврата из другого приложения: запаздывающий фокус окна Windows больше не отклоняет нажатие. Чтение буфера разрешено один раз по настоящему нажатию кнопки вставки мышью или клавиатурой; программные нажатия и посторонние окна не получают доступ.
- Дополнены инструкции DeviantArt на русском и английском: адрес перенаправления, возврат к списку приложений для получения Client ID и Client Secret, вставка кнопкой или Ctrl+V.

## 0.5.19 — 2026-10-17

- Источники представлены плитками: описание, доступность ключа, переключатель, вставка из буфера, сохранение и очистка данных доступа. Один раздел используется на главном экране и в настройках. Черновики полей сохраняются при опросе состояния и переходах между разделами.
- Добавлены DeviantArt, Pixabay и Konachan. Новые площадки отключены по умолчанию. DeviantArt использует личные клиентские данные, автоматически обновляет токен просмотра и получает только разрешённые автором оригиналы. Konachan поддерживает категории контента без ключа.
- Pixabay работает по кнопке подбора: ответы API кешируются на сутки, автоматические запросы отключены. Разрешение определяется доступом API. Авторство и ссылка на оригинал сохраняются.
- Общий профиль поиска учитывает теги понравившихся изображений со всех источников, включая сохранённые оценки. Локальный CLIP использует общий набор положительных и отрицательных примеров независимо от площадки.
- NASA и Wikimedia Commons используют общие интересы для запросов. Исключения учитывают пробелы и подчёркивания между источниками, не меняя сохранённые списки.
- Вставка из буфера в настольном приложении выполняется только после нажатия в активном основном окне. Ключи не возвращаются в публичном состоянии и не включаются в экспорт.

## 0.5.18 — 2026-10-17

- Исправлены запросы с многословными интересами и исключёнными тегами: названия заключаются в кавычки, поэтому части исключённого тега больше не становятся обязательными словами поиска. Исключения с запятыми и кавычками также сохраняются одним условием.
- Запросы поиска и сведений об обоях Wallhaven используют общий интервал не менее 1,5 секунды. При HTTP 429 повторные запросы останавливаются минимум на минуту, учитывается более длительный Retry-After. Автоматизация показывает ожидание повторной попытки.
- Подбор по интересам и подбор для разнообразия запоминают страницы отдельно. Переключение между ними больше не сбрасывает прогресс и не заставляет постоянно перебирать начало каталога. Прежний сохранённый прогресс переносится при первом запуске соответствующего режима.
- При ограничении Wallhaven обработка порции прекращается без серии заведомо неудачных запросов. Остальные настройки, фильтры и ограничения количества обоев сохраняются.
- Выбранная иконка отображается также в боковой панели приложения. Новый файл экспорта называется wallwave-export.json; восстановление прежних экспортов wallbloom-export.json сохраняется.
- В руководство на русском и английском добавлена проверка выключенного фонового подбора и состояния автоматизации.

## 0.5.17 — 2026-10-17

- До 1000 тегов отдельно в интересах, исключениях и настройках мониторов. Ошибки количества и длины тегов объясняются явно. Большие списки сохраняются без прежнего ограничения размера запроса; запросы к Wallhaven остаются короткими, все исключения проверяются перед загрузкой оригинала.
- В интересах и исключениях появились поиск по части названия, счётчики, просмотр по 30 тегов и удаление отдельных тегов. Поддерживаются обе языковые раскладки и теги с запятыми. Изменения применяются после сохранения настроек.
- Добавлены отдельные правила автоочистки для четырёх папок библиотеки с порогом 1–1000 показов. По умолчанию все новые правила выключены. Используется общий счётчик обоев для любых мониторов; текущие обои защищены до смены на всех экранах, перед очисткой предусмотрена минутная отсрочка.
- Не понравившиеся и исключённые обои не имеют отдельного порога показов: их копии очищаются через 5 минут после оценки, с сохранением оценок и защиты от повторного скачивания.
- Счётчик показов виден в дополнительных действиях карточки. Оценки и данные для защиты от повторной загрузки сохраняются, личные файлы в папках-источниках не удаляются.
- На узких экранах кнопка сохранения больше не перекрывается плавающей панелью статуса. Новые настройки и подсказки доступны на русском и английском языках.

## 0.5.16 — 2026-10-16

- Поля глобальных сочетаний записывают нажатия клавиш: достаточно выбрать поле, нажать, например, Alt+1 и сохранить настройки. Поддерживаются русская и английская раскладки, функциональные клавиши и цифровой блок.
- Во время редактирования собственные глобальные сочетания временно отключаются, чтобы не перехватывать ввод. После завершения редактирования они восстанавливаются. Backspace/Delete очищает поле, Escape отменяет ввод; Tab сохраняет переход между полями.
- Подсказки обновлены на русском и английском языках.

## 0.5.15 — 2026-10-16

- У отключённого источника добавлена кнопка удаления всех его копий обоев, включая понравившиеся. Подтверждение обязательно: «Нет» доступно сразу, «Да, удалить» — через 3 секунды. Сервер также проверяет задержку, состояние источника и срок подтверждения.
- Обои с исключёнными тегами очищаются автоматически через минуту либо вручную из настроек. Удаление исключения до очистки отменяет её; пауза приостанавливает автоматическую задачу. Учитываются точные имена тегов, в том числе с запятыми, без учёта регистра.
- Очистка удаляет только копии библиотеки и убирает их из галереи и истории возврата. Личные оригиналы, оценки, отпечатки для защиты от повторного скачивания и текущий отрисованный рабочий стол сохраняются.
- Диалог, подсказки и описание новых функций доступны на русском и английском языках.

## 0.4.0

Настройки разделены на интересы, автоматизацию, изображения, AI, клавиши, мониторы и резервные копии. В библиотеке видны статусы загрузки, анализа и смены, число неоценённых и понравившихся обоев, занятое место.

Нажмите **«Кадр»** на скачанных обоях, выберите монитор и режим: **«Заполнить экран»** обрезает края, **«Вписать целиком»** сохраняет всё изображение с полями. Ползунки перемещают кадр, переключатель отражает его по горизонтали. Предпросмотр использует пропорции выбранного экрана. «Сохранить кадр» меняет настройки для следующей установки; «Сохранить и установить» сразу применяет их.

Кадр можно открыть и из раздела **«Мониторы»**. Шаблон монитора действует на обои без индивидуальных настроек; собственный кадр имеет приоритет. Кнопка «Убрать свой кадр» возвращает шаблон. Для каждого подключённого монитора приложение создаёт изображение его разрешения. Успешная смена заменяет только предыдущую подготовленную копию; исходник остаётся.

Новые загрузки сохраняют полный исходник. Он учитывается в лимите диска и включается в экспорт вместе с настройками кадра. Старые экспорты версии 0.3 также восстанавливаются. Если у старых обоев исходник ещё не сохранён, редактор использует кеш и предлагает **«Обновить исходник»** из включённого источника. Если источник больше недоступен, сохранённая копия остаётся доступна, но ранее обрезанные края восстановить из неё нельзя.

## 0.3.0

- В настройках выберите число показов до замены (2–10, по умолчанию 3), запас неоценённых обоев и разнообразие 0–100. Для пополнения включите автоматический поиск. Автоматические загрузки поддерживают заданный запас; ручная загрузка может добавить больше. Часть поиска при повышении разнообразия обращается к общим популярным обоям, сохраняя ограничения контента и исключённые теги.
- Показ считается после 30 секунд активности с разблокированным экраном вне полноэкранной работы. Счётчики служебные, история показов не добавлена. При игре, блокировке и батарее автоматические задачи откладываются. Случайная смена использует сохранённые счётчики, чтобы пройти доступные изображения до повторов.
- Выбирай монитор в библиотеке перед установкой обоев. В настройках есть отдельные категории, интересы и таймер для каждого монитора. Расписание принимает время через запятую: `09:00, 18:00` по часам Windows. Запуск с Windows включается через трей; смена при запуске и после пробуждения настраивается отдельно.
- Кнопка «Для работы» ставит спокойный нейтральный фон и скрывает взрослые изображения. Режим сохраняется до явного действия «Выйти из режима работы». Глобальные сочетания задаются в настройках, например `Ctrl+Alt+N`; пустое поле отключает действие. Если сочетание занято, под полем появится сообщение. Новые действия доступны в трее.
- Для экспорта укажите существующую папку: внутри появится новая папка `WallWave-export-…`. Для восстановления укажите эту папку целиком. Экспорт содержит скачанные обои, настройки и оценки; API-ключи не включаются. Перед заменой прежняя библиотека сохраняется в `library.before-restore-…`. После восстановления нажмите «Продолжить» в библиотеке или трее. Для полного отката закройте программу через «Выход», переименуйте новую `library` и верните прежней папке имя `library`.
- Настройки кадра добавлены в версии 0.4.0. Второй монитор и события сна проверены на уровне логики; для проверки реального оборудования нужен второй подключённый экран.
