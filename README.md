# WallWave

[Русский](#русский) · [English](#english)

## Русский

**Обои под ваши предпочтения.** WallWave подбирает изображения для рабочего стола Windows. Отмечайте понравившиеся — ваши оценки помогают улучшать подбор.

### Начало работы

1. Запустите **`WallWave-Windows-x64.exe`**.
2. Укажите ваши интересы в **настройках**.
3. Выберите обои и нажмите **«Установить»**.

**Готовая сборка не требует Node.js.** Настройки и оценки сохраняются на вашем компьютере.

**Закрытие окна оставляет приложение в трее.** Чтобы завершить работу, выберите **«Выход»** в меню значка рядом с часами.

Проект находится **в разработке**. [История изменений](CHANGELOG.md) · [Техническая документация](docs/DEVELOPMENT.md) · [Лицензия MIT](LICENSE)

## English

**Wallpapers that match your taste.** WallWave recommends wallpapers for your Windows desktop. Rate the images you like to improve recommendations.

1. Run **`WallWave-Windows-x64.exe`**.
2. Choose your interests in **Settings**.
3. Select a wallpaper and click **Set wallpaper**.

**The compiled app does not require Node.js.** Settings and ratings are stored on your computer.

**Closing the window keeps the app in the system tray.** Select **Quit** from the tray menu to exit completely.
