## 🚀 Первый запуск — от скачивания до новых обоев

**Для готового приложения не нужны навыки программирования или установка дополнительных пакетов.** Нужна 64-разрядная Windows и подключение к интернету для онлайн-источников.

1. **Скачайте [WallWave.exe](https://github.com/yurgenium/WallWave/releases/latest/download/WallWave.exe).** На [странице выпуска](https://github.com/yurgenium/WallWave/releases/latest) он находится в блоке **Assets** («Файлы выпуска»). Архивы **Source code** содержат исходники и для обычного запуска не нужны.
2. **Запустите скачанный файл двойным щелчком.** При первом запуске выберите место размещения. В нём появится папка **WallWave** с файлами приложения. Дождитесь распаковки и открытия окна.
3. **Откройте «Настройки → Интересы и контент».** Укажите несколько интересов через запятую, например `nature, mountains, space`, и нажмите **«Сохранить»**. Для начала можно оставить остальные параметры по умолчанию.
4. **Проверьте «Источники».** Wallhaven включён изначально. Для личных изображений добавьте источник «Локальная папка» и укажите папку с обоями. Этот же раздел доступен в настройках.
5. **Нажмите «Ручная загрузка обоев»** на главном экране и дождитесь окончания. Откройте понравившееся изображение и нажмите **«Установить»**. Загрузка сама по себе не меняет текущий фон.
6. **Оцените несколько изображений.** Лайки и дизлайки постепенно помогают уточнять подбор. Автоматическую загрузку, смену обоев и ИИ можно включить позже, когда основные настройки уже подходят.

> **С чего начать:** безопасная категория **SFW**, до **12 изображений за поиск**, лимит **30 непросмотренных обоев**. ИИ и автоматическая смена по умолчанию выключены — их можно включить отдельно.

**Повторный запуск:** откройте `WallWave.exe` в выбранной папке **WallWave**. Место установки запоминается; заново выбирать его каждый раз не требуется.

| **Библиотека с оценками** | Понравившиеся, нейтральные и отложенные обои легко найти отдельно. Повторы отсекаются при загрузке. |
| **Автоматическое пополнение и смена** | Можно задать интервалы и расписание. Фоновые задачи учитывают простой и нагрузку компьютера. |
| **Отдельные профили** | Раздельные библиотеки, оценки, теги, настройки и источники; при создании можно скопировать настройки основного профиля. |
| **Собственные папки** | Собирайте подборки без копирования файлов и включайте показ только выбранной папки с длительным циклом без повторов. |
| **Закрепление обоев** | Оставьте текущие обои на 1, 6, 12 часов, до ручной смены или выбранного времени через меню трея. |
| **Несколько мониторов** | Для экранов доступны отдельные параметры смены, категорий и кадрирования. |

| **Необязательный локальный ИИ** | CLIP сравнивает изображения с оценёнными и проверяет миниатюры перед скачиванием оригиналов. |
| **Быстрые действия** | Фильтры SFW / Sketchy / NSFW находятся справа вверху библиотеки; оценки собраны в компактный блок карточки. |
| **Работа из трея** | Закрытое окно не мешает фоновой работе. Значок рядом с часами позволяет открыть приложение, включить паузу или выйти. |
| **Экспорт и восстановление** | Библиотеку, настройки и оценки можно экспортировать; API-ключи в экспорт не включаются. |
| **Русский и английский** | Язык интерфейса выбирается в настройках. |

В карточках отображается **источник изображения**. Подробности и ссылка на исходную страницу доступны в меню дополнительных действий.

Теги с запятой записываются в кавычках: `"название, с запятой", nature`. Нажатие на тег в карточке добавляет его целиком; правое нажатие управляет исключением.

Отключение источника скрывает его неоценённые изображения. Удаление источника освобождает такие копии из библиотеки; оценённые изображения и личные исходные файлы сохраняются.

## 👤 Профили, папки и закрепление

Откройте **Настройки → Профили**, чтобы создать, переименовать или переключить профиль. Новый профиль начинает с пустой библиотеки. Флажок копирования переносит настройки основного профиля, включая теги; изображения, оценки и ключи остаются раздельными. Удаление доступно для неактивного дополнительного профиля; его данные сохраняются локально для восстановления.

Кнопка **+** рядом с папками библиотеки создаёт собственную папку. Кнопка папки в карточке добавляет изображение в подборку, сохраняя текущий просмотр и оценку. Для смены обоев из одной подборки выберите её показ. Одно изображение может входить в несколько папок.

В меню значка рядом с часами доступны **предыдущие обои** и **закрепление текущих**. После завершения закрепления приложение сменит обои и вернётся к обычному расписанию. Время вводится в 24-часовом формате; двоеточие добавляется автоматически.

Если компьютер становится занят игрой или рендером, текущая работа ИИ останавливается. После отмены загрузки автоматический подбор приостанавливается на час; длительность можно изменить в настройках автоматизации. Ручной подбор снимает эту паузу. Кнопка повтора незавершённых загрузок продолжает скачивание уже найденных вариантов. При ошибке можно скачать диагностический отчёт и открыть журнал; отчёт не содержит API-ключей и личных тегов.

## 🎛️ Плавающая панель

В свёрнутом виде панель показывает текущий статус. Раскройте её стрелкой, чтобы увидеть две шкалы подбора, следующую смену, закрепление и быстрые действия. Пауза **смены обоев** не останавливает загрузку. Общий интервал не перезаписывает персональные интервалы мониторов; в списке папок можно выбрать свою подборку. При наведении на перекрытую карточку панель **плавно скрывается**, освобождая её для просмотра и нажатия. После ухода указателя панель возвращается на прежнее место. Наведение в её область прерывает исчезновение до ухода с карточки. **Развёрнутая панель не скрывается.** У скрытой панели остаётся маленький значок возврата у правого края.

**Настройки → Помощь и диагностика** содержит журнал, локальный отчёт и ссылку для сообщения об ошибке. В панели обращение к диагностике появляется при потере связи с приложением или серьёзной ошибке сохранения.

## ➕ Добавление сайтов

В разделе **Источники** нажмите **Добавить сайт**, вставьте адрес и выберите **Определить подключение**. Для известных площадок появятся нужные поля и инструкция: API-ключ, Client ID / Client Secret или ID пользователя с ключом. Кнопка **Проверить поиск и миниатюру** проверяет безопасный запрос `landscape`, не скачивая оригиналы и не изменяя библиотеку. Она не гарантирует результаты по личным интересам. Сохранение подключения — отдельное действие.

Для новых сайтов поддерживается распознавание совместимых **Danbooru JSON**, **Gelbooru / DAPI JSON** и JSON-каталогов WallWave. При необходимости формат и способ авторизации можно выбрать вручную и проверить. Подключается поиск по сайту; адрес автора или раздела не ограничивает подбор. Неизвестный сайт можно предложить через **Запросить поддержку сайта**: откроется форма GitHub Issues, которую пользователь проверяет и отправляет самостоятельно. В ссылку запроса передаётся только адрес сайта без параметров и данных доступа.

Локальные папки и явные JSON-каталоги доступны в раскрываемом блоке добавления источника. Новые сайты не включаются автоматически при обновлении.

## 🌐 Источники и общий профиль вкусов

В **«Источниках»** каждая площадка представлена плиткой: описание, переключатель, состояние доступа и кнопки настройки. Вставка из буфера заполняет поле; данные применяются после **«Сохранить»**. Затем источник можно включить. Раздел доступен и на главном экране, и в настройках.

| Источник | Что требуется | Режим |
| --- | --- | --- |
| **Wallhaven** | Ключ нужен для NSFW; для SFW не обязателен | Ручной и фоновый подбор |
| **DeviantArt** | Личные Client ID и Client Secret | Ручной и фоновый подбор; только работы с разрешённым скачиванием |
| **Pixabay** | Личный API-ключ | Подбор по кнопке, SafeSearch; кеш ответов на 24 часа |
| **Konachan** | Ключ не требуется | Ручной и фоновый подбор с выбранными SFW / Sketchy / NSFW |
| **Bing, NASA Images, Wikimedia Commons** | Ключ не требуется | Ручной и фоновый подбор |
| **Локальные папки** | Путь к папке с изображениями | Личные оригиналы сохраняются |

**Как получить доступ:** для Pixabay откройте [страницу API](https://pixabay.com/api/docs/) после входа в аккаунт, скопируйте ключ и вставьте его в плитку. Для DeviantArt откройте [настройки приложений](https://www.deviantart.com/studio/apps), создайте личное приложение типа **Confidential**. В поле **OAuth2 Redirect URI Whitelist** укажите `http://localhost/`. После сохранения вернитесь на страницу списка приложений: там доступны **Client ID** и **Client Secret**. Перенесите их в соответствующие поля WallWave кнопками вставки или сочетанием **Ctrl+V** и нажмите **«Сохранить»**. Пароль аккаунта WallWave не требуется; токены просмотра обновляются автоматически. [Документация доступа DeviantArt](https://deviantart.readme.io/docs/authentication).

За один запуск Pixabay проверяется одна страница, до 24 кандидатов; после фильтрации результат может быть меньше выбранной порции. Pixabay используется по кнопке: его [правила API](https://pixabay.com/api/docs/) требуют кеширования ответов на сутки и ограничивают автоматические запросы и массовое скачивание. Обычный доступ API может предоставлять изображения до 1280 пикселей; более высокое разрешение используется, если оно доступно аккаунту.

**Вкусы общие для всей библиотеки.** Например, оценки пейзажей с DeviantArt помогают отбирать похожие изображения с Wallhaven и Konachan. Теги понравившихся работ дополняют поисковые запросы подключённых площадок. Каждая площадка выполняет собственный поиск и предоставляет файл, а при включённом ИИ локальный **CLIP** проверяет визуальное соответствие предпочтениям перед скачиванием оригинала. Ручные интересы и исключения сохраняются; их не нужно вводить заново. Для надёжного отсеивания ИИ по-прежнему нужны положительные и отрицательные примеры.

Новые площадки после обновления **отключены по умолчанию**. Уже включённые источники и сохранённые данные доступа сохраняются. Теги с пробелами, запятыми и кавычками автоматически передаются в Wallhaven корректно; пробелы и подчёркивания учитываются при сопоставлении исключений между площадками.

## 🧹 Очистка библиотеки

- **По количеству показов:** в «Настройки → Автоматизация» можно отдельно выбрать папки и задать каждой порог **от 1 до 1000 показов**. Новые правила изначально выключены. Показ засчитывается после 30 секунд видимого рабочего стола и сохраняется в общем счётчике обоев независимо от монитора; одновременный показ одного изображения на нескольких экранах считается одним. Текущие обои защищены до смены на всех мониторах. Затем начинается минутная отсрочка, в течение которой можно отключить правило и сохранить настройки. Уже накопленные показы учитываются. Количество показов видно в меню «Другие действия» карточки.

- **Обои отключённого источника:** откройте «Источники», отключите нужный источник и нажмите **«Удалить обои этого источника»**. Удаляются все его копии из библиотеки, включая понравившиеся. В окне подтверждения **«Нет» доступно сразу**, а **«Да, удалить» — через 3 секунды**.
- **Исключённые теги:** после сохранения настроек совпадающие обои автоматически удаляются **через минуту**, включая понравившиеся. Совпадение проверяется по полному имени тега, без учёта регистра. Если убрать тег из исключений и сохранить настройки до очистки, удаление отменится. Пауза приложения приостанавливает автоматическую очистку; занятая программа выполнит её позднее.
- **Очистить по тегам сразу:** в «Настройки → Интересы и контент» доступна кнопка **«Удалить обои с исключёнными тегами»** с таким же подтверждением.

**Удаление копий необратимо.** Личные файлы в папках-источниках сохраняются. Оценки и отпечатки остаются для защиты от повторного скачивания; очищенные изображения исчезают из галереи и истории возврата. Уже установленные обои сохраняются на рабочем столе до следующей смены. При обновлении с прежней версии минутная отсрочка применяется и к уже сохранённым исключённым тегам.

## 👍 Как работают оценки

В списках интересов и исключений допускается **до 1000 тегов в каждом**, длина одного тега — до 80 символов. Под полями есть **поиск по части названия**, счётчики и удаление отдельных тегов. Большие списки отображаются страницами по 30 тегов. Поиск ничего не меняет; редактирование и удаление применяются после **«Сохранить»**. Тег с запятой в текстовом поле указывается в кавычках: `"artist, sample"`.

| Действие | Результат |
| --- | --- |
| **Нравится** | Положительный пример для подбора похожих изображений. |
| **Не нравится** | Отрицательный пример: похожие изображения получают более низкий приоритет. |
| **Исключить** | Убирает конкретное изображение из дальнейшей смены. Не считается дизлайком для ИИ. |
| **Нейтрально** | Отмечает изображение как просмотренное, без обучения предпочтениям. |
| **Отложить** | Переносит обои в отдельную подборку и исключает из автоматической смены. |

Дизлайк применяется через **5 секунд**; за это время действие можно отменить. **«Отложить» применяется сразу**, без таймера. Если исключить текущие обои, приложение подберёт замену из доступной библиотеки. Исходные файлы в подключённой личной папке сохраняются.

Кнопка рядом с левой стрелкой в просмотре возвращает к **трём последним оценённым обоям**; доступны также **Q / Й** и **↑**. Файлы старых дизлайков и исключений освобождаются, а оценки и отпечатки сохраняются для защиты от повторной загрузки. Файлы дизлайков и исключений сохраняются до 5 минут для возврата; текущие обои защищены до смены. Новые правила очистки по показам применяются только к неоценённым, понравившимся, нейтральным и отложенным.

## 🧠 Как включить ИИ и выбрать режим

1. Сначала отметьте изображения, которые нравятся и не нравятся.
2. В настройках метода подбора выберите **«CLIP: 1 поток CPU»** или **«CLIP: до 2 потоков CPU»**.
3. В параметре **«Отбор перед скачиванием»** оставьте **«Осторожный»**. Это подходящий начальный вариант; строгий режим можно попробовать позднее.

| Режим отбора | Что происходит перед скачиванием |
| --- | --- |
| **Выключен** | Предварительная проверка вкусов не используется. |
| **Осторожный** | Отклоняются явно неподходящие изображения; их оригиналы не скачиваются. Нужны минимум **5 лайков и 5 дизлайков**. |
| **Строгий** | Отклоняется больше сомнительных совпадений. Нужны минимум **3 лайка и 3 дизлайка**; подходящих загрузок может быть меньше. |

Пока оценок недостаточно, фильтр пропускает изображения и накапливает примеры. Это вероятностная оценка вкусов, а не гарантия точного совпадения. **Исключения не заменяют дизлайки.**

ИИ работает на компьютере, использует **1–2 потока CPU, без GPU**. Требуется не менее **8 ГиБ оперативной памяти**, из них около **3 ГиБ свободно**. При первом использовании загружается модель — примерно **90 МБ**; затем анализ выполняется локально. Фоновый анализ ожидает двух минут простоя. Проверка миниатюр при ручной загрузке выполняется в ходе подбора, если позволяют ресурсы.

Если ИИ отклоняет изображение, его оригинал не скачивается. Без доступной миниатюры осторожный режим допускает загрузку без проверки, строгий откладывает её. При нехватке ресурсов проверка и загрузка могут быть отложены. **Существующая библиотека и личные исходные файлы автоматически не очищаются по оценке ИИ.**

### Обучаемый подбор

Необязательная настройка в разделе метода подбора, по умолчанию выключена. У каждого профиля своя модель. Она обучается только на этом компьютере и использует уже полученные данные, поэтому не добавляет запросов к сайтам сверх лимита одного обновления.

- **Выбор новых обоев:** скачиваются те, что модель оценила выше порога. Часть (15–20%) выбирается случайно, чтобы находить новое.
- **Настройка по лайкам:** приложение сравнивает долю лайков у обоев, выбранных моделью, и у случайных. Если модель выигрывает, отбор становится строже, если нет, мягче.
- **Смена обоев:** при запросе вручную ставятся обои с наивысшей оценкой, при автоматической смене учитываются и оценка, и то, как давно обои показывались. Недавно показанные обои не возвращаются, даже лайкнутые. Обои, заменённые вручную вскоре после появления, считаются промахом и показываются реже, реакция на них не меняется. При нескольких заменах подряд похожие обои опускаются, а треть запросов берётся из лайкнутых. Лайк обоям на рабочем столе считается удачным выбором и весит при обучении вдвое больше.
- **Исключённые обои:** по переключателю учитываются как «тема интересна, не подошло именно это изображение». Модель использует их, даже если файлы уже удалены. Объяснить словами, что именно не понравилось, она не может.

Нужно не меньше **5 лайков и 5 отрицательных оценок** и включённый метод подбора CLIP. Это вероятностная оценка: понравившихся обоев должно становиться больше, но не все.

## ⚙️ Два разных лимита загрузки

- **«Изображений за поиск»** — сколько новых обоев приложение пытается скачать за одно нажатие. После повторов и отклонений поиск продолжается на следующих страницах, пока не набрана порция или не достигнуто ограничение.
- **«Лимит непросмотренных обоев»** — сколько уже скачанных изображений без оценки разрешено накопить. Значение **0** отключает этот лимит.

Например, при порции **12** и наличии **28 из 30** непросмотренных обоев будет скачано не больше **2**. Чтобы освободить место в таком пуле, можно оценить изображения или изменить лимит.

Реально подходящих новых обоев может оказаться меньше порции. Приложение показывает частичный результат и причину остановки: закончились варианты, сработал фильтр, достигнут предел проверки или возникла ошибка. Подробности находятся в **«Журнале»**.

**Ограничение времени:** новые поиски и загрузки не начинаются после восьми минут подбора. Уже начатые передачи завершаются в пределах своего тайм-аута; сохранённые файлы остаются в библиотеке. При медленной сети результат может быть частичным.

**Две шкалы подбора:** «Подготовлено» считает обои, прошедшие отбор, включая уже скачанные и ожидающие загрузки. «Скачано» считает только сохранённые файлы. Например, **9 из 24 подготовлено, 5 из 24 скачано** означает, что ещё 4 изображения загружаются или стоят в очереди. Просмотренные и отклонённые кандидаты в эти числа не входят; шкалы не переключаются на байты отдельного файла.

Подбор держит небольшую очередь и передаёт **до двух оригиналов одновременно**. Проверка миниатюры предшествует запросу полных данных; сведения Wallhaven кешируются на сутки. При равной оценке раньше выбираются меньшие файлы. Медленные файлы откладываются, а ошибки одной площадки не мешают остальным. Запросы API идут с интервалами и учитывают ограничения источника. **«Продолжить подбор»** запускает такую же ограниченную партию, вместо скачивания всех когда-либо найденных кандидатов.

Время зависит от скорости площадки, размера оригиналов и количества подходящих изображений. Если источник сообщает лимит скачиваний, он временно пропускается; причина видна в его плитке. Параметры качества и режим фильтра предпочтений сохраняются.

## 📁 Где находятся обои и настройки

**Папка данных:**

```text
%USERPROFILE%\WallWave\library
```

Чтобы открыть её, нажмите **Win + R**, вставьте путь и нажмите **Enter**. Здесь находятся изображения, оценки, настройки, параметры источников и API-ключи. Это отдельная папка от установленного приложения.

Для резервной копии можно воспользоваться разделом **«Экспорт и восстановление библиотеки»** в настройках. Экспорт не включает API-ключи. Если нужна полная ручная копия, сначала завершите приложение через трей и скопируйте папку данных.

## 🔄 Как обновить приложение

1. Нажмите правой кнопкой на значок WallWave рядом с часами и выберите **«Выход»**. При необходимости раскройте скрытые значки кнопкой `˄`.
2. Скачайте EXE нового выпуска и запустите его.
3. Программа использует сохранённую папку приложения. **Обои, оценки и настройки сохраняются**, повторно настраивать библиотеку не требуется. В `WallWave\app` остаются две предыдущие версии для отката, более старые удаляются автоматически.

Раз в день приложение проверяет на GitHub, вышла ли новая версия, и сообщает о ней. Устанавливается она вручную. Проверку можно выключить в **«Настройки → Обновления»**, там же есть ссылка на страницу выпусков.
