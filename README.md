# WallWave

[Русский](#русский) · [English](#english)

## Русский

Локальное приложение для подбора обычных обоев в Windows. Рабочее название — WallWave. Самостоятельный проект: Wallpaper Engine и Steam не нужны. Версия 0.4 — Windows-приложение с отдельным окном и треем; для готового EXE браузер, Node.js и консоль не требуются.

### Запуск

1. Дважды нажми ярлык `WallWave` в папке проекта или `dist/WallWave-Windows-x64.exe`. Для распакованной сборки запускай `dist/win-unpacked/WallWave.exe`, сохраняя остальные файлы этой папки рядом.
2. Откроется отдельное окно приложения. В настройках укажи разрешение, интересные теги и включи автоматический поиск/смену по желанию. Язык переключается в боковой панели.
3. Закрытие окна оставляет программу в трее рядом с часами. Окно освобождает память; значок позволяет открыть его снова.
4. В меню значка доступны «Открыть библиотеку», «Пауза»/«Продолжить», ручная загрузка, «Запускать с Windows» и «Выход». Только «Выход» полностью останавливает приложение и его фоновые задачи. Автозапуск по умолчанию выключен.
5. Цвет и подпись значка показывают состояние: работает, ждёт простоя, на паузе или требует внимания. При первом закрытии окна появляется пояснение о работе в фоне.
6. При первом запуске из папки проекта старая библиотека копируется в `%USERPROFILE%/Wallbloom/library`, если новой библиотеки ещё нет. Перенос идёт через отдельную временную папку без перезаписи существующих данных; старая папка сохраняется. Настройки, оценки и API-ключи также сохраняются в файлах `.backup`: если основной файл пропал или повреждён, он автоматически читается из резервной копии. Удаление ключа очищает и его резервную копию.

Для разработчика: Node.js 22.12+, `npm install`, `npm test`, `npm start` запускает окно Electron. `npm run start:web` оставляет прежний браузерный режим на <http://127.0.0.1:43198>. Сборка: `npm run build:win` или `pnpm run build:win`. Есть `pnpm-lock.yaml`; альтернативно `pnpm install --frozen-lockfile`. Desktop-сервис выбирает свободный локальный порт сам; его нельзя считать постоянным. Папку данных можно задать `WALLBLOOM_DATA_DIR`. Для однократного переноса другой библиотеки используй `WALLBLOOM_IMPORT_DATA_DIR`.

### Что реализовано

- Переключение русского и английского интерфейса, включая сообщения об ошибках.
- В библиотеке категории SFW / Sketchy / NSFW включаются независимо, кнопками или клавишами F1 / F2 / F3. Выбор сохраняется и влияет на показ, поиск, скачивание и ротацию. Хотя бы одна категория должна оставаться включённой. Ручная загрузка — второстепенная кнопка; «Улучшить подбор» ставит анализ CLIP в ожидание простоя.
- Категории safe, suggestive и 18+. Это категории источника, не сертифицированная возрастная классификация и не автоматический анализ безопасности изображений.
- Wallhaven: популярные за день, 3 дня, неделю, месяц, 3/6 месяцев или год; новые страницы при повторных поисках. Смена настроек сбрасывает пагинацию.
- Локальные папки: JPEG, PNG, WebP, AVIF, вложенность до 6 уровней, до 500 файлов. Подпапки используются как теги. Символические ссылки пропускаются.
- Пользовательские каталоги JSON по HTTPS. Любые источники можно включать и отключать. Период популярности поддерживает только Wallhaven; произвольный каталог сортируется по переданному числу `popularity`.
- Лайк учит предпочтения; дизлайк уменьшает похожие результаты; бан исключает отдельное изображение. Оценку можно сбросить.
- Реальные папки `data/pending`, `liked`, `disliked`, `blocked`. В каждой есть `index.json`. Если загрузка не удалась, запись остаётся в ожидании оценки с ошибкой и кнопкой повтора.
- Прогресс загрузки, результат и ошибка каждого источника, журнал последних 60 событий, занимаемый объём, путь библиотеки и время поиска. Изображения показываются из локального кэша; до скачивания карточка явно подписана.
- Уменьшение на CPU до заданных размеров, JPEG с выбором качества, варианты с полями/обрезкой/вписыванием. Автоматического увеличения нет; исходные файлы в локальной папке не изменяются. Изменённые параметры действуют на следующие загрузки.
- Лимиты размера файла и общего объёма. При превышении загрузка останавливается; неоценённые обои обновляются после 2–10 реальных показов только при успешной загрузке замены; оценки и исходные файлы источников сохраняются.
- Автоматическое пополнение после 2 минут простоя. Смена обоев ждёт отсутствия полноэкранных приложений и процессов из списка. В desktop-версии сервис работает, пока приложение остаётся в трее. Пауза отменяет текущую задачу и останавливает автоматические задачи; сохраняется между запусками. Ручная установка/возврат обоев остаются доступны.

### Новое в 0.4.0

Настройки разделены на интересы, автоматизацию, изображения, AI, клавиши, мониторы и резервные копии. В библиотеке видны статусы загрузки, анализа и смены, число неоценённых и понравившихся обоев, занятое место.

Нажми **«Кадр»** на скачанных обоях, выбери монитор и режим: **«Заполнить экран»** обрезает края, **«Вписать целиком»** сохраняет всё изображение с полями. Ползунки перемещают кадр, переключатель отражает его по горизонтали. Предпросмотр использует пропорции выбранного экрана. «Сохранить кадр» меняет настройки для следующей установки; «Сохранить и установить» сразу применяет их.

Кадр можно открыть и из раздела **«Мониторы»**. Шаблон монитора действует на обои без индивидуальных настроек; собственный кадр имеет приоритет. Кнопка «Убрать свой кадр» возвращает шаблон. Для каждого подключённого монитора приложение создаёт изображение его разрешения. Успешная смена заменяет только предыдущую подготовленную копию; исходник остаётся.

Новые загрузки сохраняют полный исходник. Он учитывается в лимите диска и включается в экспорт вместе с настройками кадра. Старые экспорты версии 0.3 также восстанавливаются. Если у старых обоев исходник ещё не сохранён, редактор использует кеш и предлагает **«Обновить исходник»** из включённого источника. Если источник больше недоступен, сохранённая копия остаётся доступна, но ранее обрезанные края восстановить из неё нельзя.

### Новое в 0.3.0

- В настройках выбери число показов до замены (2–10, по умолчанию 3), запас неоценённых обоев и разнообразие 0–100. Для пополнения включи автоматический поиск. Автоматические загрузки поддерживают заданный запас; ручная загрузка может добавить больше. Часть поиска при повышении разнообразия обращается к общим популярным обоям, сохраняя ограничения контента и исключённые теги.
- Показ считается после 30 секунд активности с разблокированным экраном вне полноэкранной работы. Счётчики служебные, история показов не добавлена. При игре, блокировке и батарее автоматические задачи откладываются. Случайная смена использует сохранённые счётчики, чтобы пройти доступные изображения до повторов.
- Выбирай монитор в библиотеке перед установкой обоев. В настройках есть отдельные категории, интересы и таймер для каждого монитора. Расписание принимает время через запятую: `09:00, 18:00` по часам Windows. Запуск с Windows включается через трей; смена при запуске и после пробуждения настраивается отдельно.
- Кнопка «Для работы» ставит спокойный нейтральный фон и скрывает взрослые изображения. Режим сохраняется до явного действия «Выйти из режима работы». Глобальные сочетания задаются в настройках, например `Ctrl+Alt+N`; пустое поле отключает действие. Если сочетание занято, под полем появится сообщение. Новые действия доступны в трее.
- Для экспорта укажи существующую папку: внутри появится новая папка `WallWave-export-…`. Для восстановления укажи эту папку целиком. Экспорт содержит скачанные обои, настройки и оценки; API-ключи не включаются. Перед заменой прежняя библиотека сохраняется в `library.before-restore-…`. После восстановления нажми «Продолжить» в библиотеке или трее. Для полного отката закрой программу через «Выход», переименуй новую `library` и верни прежней папке имя `library`.
- Настройки кадра добавлены в версии 0.4.0. Второй монитор и события сна проверены на уровне логики; для проверки реального оборудования нужен второй подключённый экран.

### Подбор и локальная модель

По умолчанию работает лёгкий алгоритм: теги интересов, оценки, средний цвет уже скачанных изображений. Цвет применяется для ранжирования библиотеки после загрузки; теги помогают выбирать ещё не скачанное. Поиск не обещает нейросетевого сходства в этом режиме.

Опциональная CLIP: выбери экономный или обычный режим. В готовом приложении зависимости уже включены; веса [Xenova/clip-vit-base-patch32](https://huggingface.co/Xenova/clip-vit-base-patch32) скачиваются только при первом анализе, если их ещё нет в кэше. Используется [Transformers.js](https://huggingface.co/docs/transformers.js/). Это визуальные векторы и сравнение с твоими оценками, без обучения новой нейросети и без генерации изображений.

Модель работает в отдельном процессе на CPU, 1 или до 2 потоков, с пониженным приоритетом. Не больше 8 изображений и 3 минут за запуск. Проверка свободной памяти и активности останавливает процесс; уже полученные векторы сохраняются. Пороги: 8 ГиБ общей RAM и 3 ГиБ свободно перед запуском; остановка при менее 2 ГиБ свободно. Это защитные пороги, не подтверждённые минимальные требования. GPU не используется. При первом запуске модель может не успеть скачаться за 3 минуты; повторный запуск использует кэш. Ошибка проверки активности запрещает фоновые задачи.

### Источники и 18+

На Wallhaven 18+ требует регистрации и собственного API-ключа: [документация API](https://wallhaven.cc/help/api), [настройки аккаунта](https://wallhaven.cc/settings/account). Ключ вводится в карточке источника. Интерфейс не получает сохранённый ключ обратно. Файл `data/credentials.json` хранит ключ **без шифрования**; папка `data` исключена из Git. Не публикуй её и не передавай чужим людям.

Для локальной папки явно выбирается её категория: содержимое классифицируешь ты. В пользовательском каталоге каждое изображение должно иметь категорию. При safe картинки из adult-источника не импортируются. Это доверие метаданным источника; нейросетевой модерации нет.

Свои каталоги подключаются без редактирования программы:

```json
{
  "items": [
    {
      "id": "landscape-01",
      "title": "Mountain lake",
      "url": "https://example.org/images/lake.jpg",
      "source": "https://example.org/photos/lake",
      "tags": ["nature", "mountains"],
      "rating": "safe",
      "popularity": 120
    }
  ]
}
```

Максимум 500 записей и 2 МиБ JSON. `rating`: `safe`, `suggestive`, `adult`. URL изображения — публичный HTTPS. Переадресации проверяются; приватные адреса и локальная сеть запрещены. Пользовательские API с авторизацией пока не подключаются напрямую: для них нужен отдельный адаптер. Возможность добавить любую библиотеку означает подключение папки или каталога по этому формату, а не совместимость с любым существующим API.

Ссылки на источник сохраняются. Право скачивания и использования зависит от лицензии каждой картинки; приложение не делает содержимое сторонних источников собственностью проекта. В репозиторий изображения не включаются.

### Проверка и ограничения

`npm test`: валидация настроек и сети, рекомендации по оценкам, реальный импорт, изменение размера, перенос файлов между папками, фильтрация категорий, скрытие ключа, сохранение и перезапуск сервиса. Тесты работают во временной папке и не меняют обои рабочего стола.

`node check-source.mjs`: живой запрос поиска и тегов Wallhaven, без скачивания картинок и без ключа.

`tools/check-ui.mjs`: дополнительная проверка браузера; аргумент — папка Node-пакетов, содержащая Playwright. Нужны Playwright и установленный Edge. Проверяет языки, сохранение настроек, ошибку источника, отсутствие горизонтального скролла на широком и узком экране.

На компьютере разработки проверены реальное скачивание из Wallhaven, установка на рабочий стол и квантованная CLIP: 512 конечных значений признаков, один поток CPU. Установке предшествует сохранение копии текущих обоев; кнопка возврата отключает авторотацию. Кнопка анализа ставит задачу в ожидание простоя, её можно отменить.

В собранном Windows EXE проверены изменение размера настоящих изображений, CLIP/ONNX на CPU, пауза/продолжение из меню трея, закрытие и повторное открытие окна, остановка дочернего сервиса при выходе и сохранение настроек. EXE не содержит пользовательской библиотеки и API-ключей.

Ещё требуют проверки: другие конфигурации Windows, длительная работа и измерение нагрузки, API с NSFW-ключом. Работа с отдельными мониторами, защищённое хранение ключей, обновления и подписанный установщик — будущие этапы. Апскейлинг обсуждается отдельно; CLIP не является моделью увеличения изображения.

## English

WallWave is a local Windows wallpaper recommender. Independent from Wallpaper Engine and Steam. Version 0.4 includes a standalone Windows app, tray status, pause/resume, optional startup integration and a portable EXE. No separate browser, terminal or Node.js installation is required for the compiled app.

Run `dist/WallWave-Windows-x64.exe` or the project shortcut. Choose English in the sidebar. Set your screen resolution, preferred tags and automatic search/rotation. Closing the window keeps the service in the tray; choose Quit from the tray menu to stop it completely. Downloads are stored locally; ratings move files between pending/liked/disliked/blocked folders. **Set wallpaper** changes your actual Windows desktop. Data lives in `%USERPROFILE%/Wallbloom/library`; the old project library is copied on first launch only if no destination library exists, and remains untouched.

Supported sources: Wallhaven, local folders and public HTTPS JSON catalogs (schema above). Wallhaven supports popular-over-time searches and personal API keys for adult content. Catalogs require explicit content ratings and can provide popularity scores; they do not support Wallhaven's time filter. The app trusts source ratings, without automatic content moderation. Local source files are copied and never modified. Individual image licenses still apply.

The default recommender uses tags, ratings and downloaded images' average colors. Optional local CLIP runs on CPU in a separate low-priority process, at most 1–2 threads, 8 images and 3 minutes per run. Run `install-ai.cmd` and enable it in settings. Weights download on first analysis. AI waits for 2 minutes idle and stops for user activity, fullscreen applications, configured processes or low memory. Requires 8 GiB total and 3 GiB free RAM as provisional safety thresholds. GPU is unused. Real CLIP inference and desktop changes have been verified on the development machine; other configurations and sustained resource usage still require validation.

Images are downsized with JPEG compression; small images are not enlarged. Upscaling is a separate future decision. Per-monitor control, secure key storage, updates and a signed installer are future work. Saved API keys are unencrypted in the private local library folder and must not be shared. They are excluded from the compiled executable and repository.

Developer setup: `npm install`, `npm test`, `npm start`, or install from the included pnpm lockfile. CI runs on Windows. `node check-source.mjs` checks live Wallhaven metadata. This repository contains the standalone WallWave project. Local data, keys, dependencies and builds are excluded through `.gitignore`. The working name has not been checked for uniqueness.

Хранилище Windows находится вне AppData, чтобы запуск из MSIX-приложения Codex и обычный запуск использовали одни данные. Старое хранилище переносится копированием при первом запуске, без удаления исходных файлов.
