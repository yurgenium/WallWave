# Проверки безопасности 0.4.1

Проверено 10 октября 2026 года. Это проверка известных уязвимостей зависимостей и конкретных защит приложения, а не гарантия отсутствия любых ошибок.

- Обе копии обработчика изображений обновлены до sharp 0.35.5: прямая зависимость и зависимость AI-модуля. Исправление включено через pnpm overrides и lockfile.
- Для sprintf-js 1.1.3 добавлен воспроизводимый патч в patches/. Ограничены числовая точность и размер заполнения строк; вредоносные значения проверяются тестом. Опубликованной исправленной версии пока нет, поэтому npm audit продолжает показывать одно предупреждение moderate по номеру версии.
- Итоговый audit для всех зависимостей: 0 critical, 0 high, 1 moderate с локальным исправлением. Не следует скрывать это предупреждение в CI.
- Проверены запрет приватных, специальных и туннельных адресов для источников, HTTPS, DNS-проверка и привязка проверенного IP к соединению. Проверка повторяется после перенаправлений.
- Локальный HTTP-сервис слушает только 127.0.0.1. Изменения требуют случайного токена; проверяются Host и Origin. Проверены отклонение запросов без токена и запрет чтения исходников через пути URL.
- Окно Electron использует sandbox, contextIsolation, отключённый nodeIntegration и webSecurity. Внешние ссылки не открывают окна с доступом к Node.js.
- Проверены ограничения размеров изображений и архивов, допустимые идентификаторы, защита импорта от обхода путей и ссылок. Экспорт не содержит ключей API; откат сохранён.
- Обновления открывают фиксированную HTTPS-страницу релизов GitHub. Приложение не скачивает и не исполняет обновления автоматически. Публикация будущих релизов остаётся отдельным действием владельца репозитория.
- Ключ Wallhaven хранится локально в профиле пользователя без шифрования. Он не входит в EXE, экспорт библиотеки или публичную сборку. Доступ к этому файлу остаётся у пользователя и программ с его правами.
