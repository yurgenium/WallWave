# WallWave

Запускайте **WallWave.exe** из этой папки. Файлы приложения находятся в **app/**.
При первом запуске EXE вы выбираете место; программа всегда создаёт отдельную папку **WallWave**.
При следующих запусках выбор сохранён и приложение не распаковывается заново.

Обои, настройки и оценки сохранены отдельно: **%USERPROFILE%\WallWave\library**.
Файл **installation.ini** хранит сведения о размещении приложения.

Обновление: завершите работу приложения через пункт «Выход» в меню значка рядом с часами и запустите EXE нового выпуска.
Он использует выбранную папку. Внутри **app/** остаются две предыдущие версии, более старые удаляются после запуска новой.

Закрыть приложение можно и командой: `WallWave.exe --quit`. EXE более старой версии не откатывает установку: он запускает уже установленную новую версию. Для намеренного отката запустите старый EXE с параметром `--allow-downgrade`.
