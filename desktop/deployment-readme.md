# WallWave

Запускай **WallWave.exe** из этой папки. Файлы приложения находятся в **app/**.
При первом запуске EXE ты выбираешь место; программа всегда создаёт отдельную папку **WallWave**.
При следующих запусках выбор сохранён и приложение не распаковывается заново.

Обои, настройки и оценки сохранены отдельно: **%USERPROFILE%\Wallbloom\library**.
Файл **installation.ini** хранит сведения о размещении приложения.

Обновление: заверши программу через «Выйти» в трее и запусти EXE нового выпуска.
Он использует выбранную папку. Предыдущая версия остаётся внутри **app/** для отката.
